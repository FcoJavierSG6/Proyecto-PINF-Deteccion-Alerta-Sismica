## CU-12. Consultar Recomendaciones de seguridad sísmica

* **Actor principal:** Usuario.
* **Actores secundarios:** -.
* **Descripción:** Permite al usuario acceder a recomendaciones sobre cómo actuar antes, durante y después de un terremoto.
* **Precondiciones:** El usuario se encuentra en el menú principal.

### Flujo principal
1. El usuario selecciona el desplegable de opciones principales del menú.
2. El sistema muestra el desplegable listando las opciones.
3. El usuario selecciona la opción Recomendaciones de seguridad sísmica.
4. El sistema muestra las recomendaciones (antes del terremoto, durante el terremoto y después del terremoto).
5. El usuario selecciona Salir.
6. El sistema vuelve al menú principal.

### Postcondiciones
* El usuario queda con el conocimiento de las recomendaciones.
