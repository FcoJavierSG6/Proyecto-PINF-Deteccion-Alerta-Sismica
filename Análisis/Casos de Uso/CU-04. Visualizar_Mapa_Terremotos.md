## CU-04. Visualizar mapa de terremotos

* **Actor principal:** Usuario.
* **Actor secundario:** Servicio web del ROA.
* **Descripción:** Permite al usuario visualizar sobre un mapa geográfico la ubicación de los terremotos publicados por el ROA. Los terremotos se representan mediante símbolos cuyo tamaño depende de su magnitud y cuyo color indica su antigüedad.
* **Precondiciones:** El usuario tiene instalada la aplicación.

### Flujo principal
1. El usuario accede al apartado del mapa.
2. El sistema solicita al servicio web del ROA la información de los terremotos disponibles.
3. El servicio web devuelve los datos de los terremotos.
4. El sistema obtiene las coordenadas geográficas de cada terremoto.
5. El sistema representa los terremotos sobre el mapa.
6. El sistema diferencia los terremotos mediante el tamaño de los símbolos, según su magnitud, y mediante colores, según su antigüedad.
7. El usuario visualiza la distribución geográfica de los terremotos.

### Postcondiciones
* Se muestra el mapa con la representación geográfica de los terremotos disponibles representados según su magnitud y antigüedad.

### Puntos de extensión
* **Consultar ficha de terremoto:** Cuando el usuario selecciona un terremoto en el mapa.
* **Consultar estaciones sísmicas:** Cuando el usuario decide mostrar las estaciones sísmicas.

### Flujos alternativos
* **2a. Error de conexión**
  * 2a.1 - No se puede obtener la información del servicio web del ROA.
  * 2a.2 - El sistema informa al usuario de que no ha sido posible cargar los terremotos.

* **2b. Datos de sismos ya disponibles localmente**
  * 2b.1 - El sistema reutiliza la información almacenada localmente (continúa en el paso 4).

* **3a. No existen terremotos disponibles**
  * 3a.1 - El servicio web no devuelve terremotos.
  * 3a.2 - El sistema muestra el mapa sin eventos sísmicos e informa al usuario.

* **7a. Seleccionar un terremoto**
  * 7a.1 - El usuario selecciona un símbolo correspondiente a un terremoto.
  * 7a.2 - El sistema abre la ficha de dicho terremoto (*Extend* Consultar ficha de terremoto).

* **7b. Mostrar estaciones sísmicas**
  * 7b.1 - El usuario activa la opción 'Estaciones'.
  * 7b.2 - El sistema muestra las estaciones sísmicas del ROA sobre el mapa (*Extend* Consultar estaciones sísmicas).
