## CU-02. Filtrar terremotos

* **Actor principal:** Usuario.
* **Actores secundarios:** -
* **Descripción:** Permite al usuario filtrar los terremotos del listado por periodo de tiempo, magnitud mínima y zona geográfica.
* **Precondiciones:** El usuario está consultando la lista de terremotos.

### Flujo principal
1. El usuario selecciona la opción de 'filtrar'.
2. El sistema muestra los criterios de filtrado disponibles.
3. El usuario selecciona el periodo de tiempo deseado (último día, semana, mes o año).
4. El usuario establece una magnitud mínima.
5. El usuario selecciona una zona geográfica.
6. El usuario confirma los criterios de filtrado.
7. El sistema aplica los criterios seleccionados.
8. El sistema muestra los terremotos que cumplen los criterios establecidos.

### Postcondiciones
* El usuario visualiza la lista de terremotos filtrada según su elección.

### Flujos alternativos
* **3a. Intervalo de tiempo no seleccionado**
  * 3a.1 - El sistema establece por defecto el intervalo en 'Último año' (continúa en el paso 4).

* **4a. Magnitud mínima no seleccionada**
  * 4a.1 - El sistema establece por defecto la magnitud mínima en 2.5 (continúa en el paso 5).

* **5a. Zona geográfica no seleccionada**
  * 5a.1 - El sistema establece por defecto 'Todas' (continúa en el paso 6).

* **8a. No existen resultados**
  * 8a.1 - Si ningún terremoto cumple los criterios seleccionados, el sistema informa al usuario de que no se han encontrado terremotos.

* ***a. Cancelación del filtrado**
  * *a.1 - El usuario cancela la operación y el sistema vuelve al listado sin aplicar los nuevos criterios.
