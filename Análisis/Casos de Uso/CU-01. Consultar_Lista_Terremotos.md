## 1. CU-Consultar lista de terremotos

* **Actor principal:** Usuario.
* **Actores secundarios:** Servicio web del ROA.
* **Descripción:** Permite al usuario consultar los terremotos recientes publicados por el ROA, mostrando la información ordenada cronológicamente, del más nuevo al más antiguo.
* **Precondiciones:** El usuario tiene instalada la aplicación.

### Flujo principal
1. El usuario abre la aplicación.
2. El sistema solicita al servicio web del ROA los terremotos publicados.
3. El servicio web devuelve la información disponible.
4. El sistema procesa y ordena los terremotos del más nuevo al más antiguo.
5. El sistema muestra el listado de terremotos.
6. Para cada terremoto se muestra la **fecha, hora, zona y profundidad**.
7. Para cada terremoto se muestra la **magnitud** visualmente mediante colores o tamaños diferenciados.

### Postcondiciones
* El usuario visualiza la lista de terremotos disponibles ordenados cronológicamente.

### Puntos de extensión
* **Aplicar filtros:** Se encuentra disponible después de mostrar el listado de terremotos.
* **Actualizar lista:** Se encuentra disponible después de mostrar el listado de terremotos.
* **Consultar ficha de terremoto:** Se encuentra disponible cuando el usuario pulsa un terremoto de la lista.

### Flujos alternativos
* **2a. Error de conexión**
  * 2a.1 - No se puede establecer conexión con el servicio web.
  * 2a.2 - El sistema muestra un mensaje indicando falta de conexión.

* **3a. No existen terremotos**
  * 3a.1 - El servicio no devuelve terremotos.
  * 3a.2 - El sistema muestra un mensaje indicando que no hay eventos.
