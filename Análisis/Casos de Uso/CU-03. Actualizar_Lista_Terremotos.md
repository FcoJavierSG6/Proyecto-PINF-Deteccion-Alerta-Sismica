## CU-03. Actualizar lista de terremotos

* **Actor principal:** Usuario.
* **Actor secundario:** Servicio web del ROA.
* **Descripción:** Permite al usuario actualizar manualmente la lista de terremotos para obtener los datos más recientes publicados por el ROA.
* **Precondiciones:** El usuario está consultando la lista de terremotos.

### Flujo principal
1. El usuario solicita actualizar la lista mediante el gesto de deslizar hacia abajo.
2. El sistema inicia la solicitud de actualización.
3. El sistema solicita al servicio web del ROA los terremotos más recientes.
4. El servicio web devuelve los datos disponibles.
5. El sistema procesa y ordena los terremotos del más nuevo al más antiguo.
6. El sistema actualiza la información mostrada en la lista.
7. El sistema informa al usuario de que la actualización ha finalizado.

### Postcondiciones
* La lista de terremotos contiene la información más reciente disponible.

### Flujos alternativos
* **1a. Actualización en curso**
  * 1a.1 - El usuario solicita una nueva actualización mientras existe otra en curso.
  * 1a.2 - El sistema se queda con la solicitud más reciente y descarta las demás (continúa en el paso 2).

* **3a. Error de conexión**
  * 3a.1 - Falla la conexión con el ROA.
  * 3a.2 - El sistema muestra un mensaje indicando que no se ha realizado la actualización.

* **4a. No existen nuevos terremotos**
  * 4a.1 - El servicio web no devuelve nuevos terremotos.
  * 4a.2 - El sistema mantiene el listado actual e informa al usuario de que no hay nuevos eventos.
